# Inbox

Sem patri vstupni material pro AI processing:

- nove Markdown texty
- surovy text k prepisu na clanek
- obrazky nebo odkazy na obrazky
- poznamky k nazvu, datu, tagum a kategorii

Obsah inboxu je pracovni a standardne se neverzuje. Hotovy clanek patri do `posts` a finalni obrazky do `static/images`.
